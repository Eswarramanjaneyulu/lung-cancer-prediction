Model Information

Random Forest Classifier

The final machine learning model used in this project is a Random Forest Classifier.


The model contains 200 decision trees and uses balanced class weights.


The dataset was divided into 80% training data and 20% testing data.


The metrics displayed on this page are calculated from the test dataset used during model evaluation.

⚠️
Educational Use Only

These results represent the performance of an educational machine learning model on its test dataset. They do not represent clinical accuracy or medical diagnostic performance.
