Project Overview

Machine Learning Based Prediction System

This project is an educational machine learning application developed using Python, Flask, Pandas, Scikit-learn and Random Forest Classification.


The system accepts patient-related input features and uses a trained machine learning model to generate a prediction for the LUNG_CANCER target class.

🤖

Machine Learning Model

Random Forest Classifier

The final model used in this project is a Random Forest Classifier with 200 decision trees and balanced class weights.


The model was trained using 80% of the processed dataset and evaluated using the remaining 20%.

📊
